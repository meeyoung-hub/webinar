# 🚀 웨비나 참가 신청 랜딩페이지 & 구글 스프레드시트 자동 연동

이 프로젝트는 웨비나 신청자의 **이름, 이메일 주소, 개인정보 제공 동의 여부**를 입력받아 **구글 스프레드시트(Google Sheets)에 실시간으로 자동 저장**하는 반응형 랜딩페이지입니다.

---

## 📂 파일 구조

```text
webinar-landing-page/
├── index.html                  # 랜딩페이지 메인 HTML (반응형 레이아웃, 신청 폼, 모달)
├── style.css                   # 스타일 및 애니메이션 (Pretendard 폰트, 모달 효과)
├── app.js                      # 폼 유효성 검사, 구글 시트 연동 비동기 통신 로직
├── google-apps-script.gs       # 구글 스프레드시트 데이터 적재용 스크립트 (웹 앱)
├── send-file-apps-script.gs    # C열 이메일 수신자에게 구글 드라이브 파일 발송 스크립트
└── README.md                   # 설정 및 사용 설명서
```

## ⚡ 빠른 시작 (3분 연동 가이드)

### 1단계: 구글 스프레드시트 생성 및 Apps Script 열기
1. [구글 스프레드시트](https://sheets.new)에 접속하여 새 문서를 생성합니다.
   - 시트 제목 예시: `2025 웨비나 신청자 명단`
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.

### 2단계: 연동 코드 붙여넣기
1. Apps Script 편집기 화면에 기본 작성되어 있는 `function myFunction() { ... }` 코드를 모두 지웁니다.
2. 본 프로젝트의 [`google-apps-script.gs`](google-apps-script.gs) 파일 내용을 전체 복사하여 붙여넣습니다.
3. 상단의 **[저장] (디스크 아이콘)**을 누르거나 `Ctrl+S` (`Cmd+S`)를 누릅니다.

### 3단계: 웹 앱(Web App)으로 배포하기
1. 우측 상단의 파란색 **[배포]** 버튼 클릭 ➔ **[새 배포]**를 선택합니다.
2. 왼쪽의 톱니바퀴 아이콘(유형 선택)을 클릭하고 **[웹 앱 (Web app)]**을 선택합니다.
3. 설정을 다음과 같이 지정합니다:
   - **설명**: `웨비나 신청 연동`
   - **다음 사용자로 실행**: **나(내 구글 계정)**
   - **액세스 권한이 있는 사용자**: **모든 사용자(Anyone)**  *(※ 중요: 누구나 신청서를 제출할 수 있어야 하므로 반드시 '모든 사용자'를 선택해야 합니다)*
4. **[배포]** 버튼을 누릅니다.
5. "액세스 승인(Authorize Access)" 창이 나타나면:
   - 본인의 구글 계정 선택
   - 'Google에서 확인하지 않은 앱' 경고 시 좌측 하단 **[고급]** 클릭 ➔ **[...로 이동(안전하지 않음)]** 클릭
   - **[허용(Allow)]** 클릭
6. 배포가 완료되면 생성된 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다.

### 4단계: 랜딩페이지에 웹 앱 URL 연결
두 가지 방법 중 편한 방법을 선택하세요:

- **방법 A (UI에서 바로 등록 - 추천)**:
  - 브라우저에서 `index.html`을 연 후, 신청 폼 하단의 **`구글 스프레드시트 연동 설정`** 버튼을 클릭합니다.
  - 복사한 웹 앱 URL을 붙여넣고 **[저장]**을 누르면 끝! (브라우저에 자동 기억됩니다)

- **방법 B (`app.js` 코드에 고정)**:
  - [`app.js`](app.js) 파일 9번째 줄의 `DEFAULT_SCRIPT_URL`에 복사한 URL을 입력합니다:
    ```javascript
    const DEFAULT_SCRIPT_URL = "https://script.google.com/macros/s/AKfycbx.../exec";
    ```

## 📨 구글 드라이브 파일 자동 발송 방법 (`send-file-apps-script.gs`)

1. 구글 스프레드시트의 **[확장 프로그램] ➔ [Apps Script]**로 이동합니다.
2. 좌측 파일 목록에서 **[+] (파일 추가) ➔ [스크립트]**를 클릭하고 파일 이름을 `SendMail`로 지정합니다.
3. [`send-file-apps-script.gs`](send-file-apps-script.gs) 코드 내용을 복사하여 붙여넣습니다.
4. 코드 상단 `DRIVE_FILE_ID`에 구글 드라이브 파일 링크의 ID를 넣고 저장합니다:
   - 파일 ID 예시: `https://drive.google.com/file/d/`**1A2B3C4D5E...**`/view` 중 굵은 부분
5. 스프레드시트로 돌아와 **새로고침(F5)**하면 상단에 **[🚀 웨비나 메일]** 메뉴가 생깁니다.
   - **`🧪 내 메일로 테스트 발송 (1건)`**: 내 구글 계정으로 먼저 시험 발송
   - **`📨 신청자 전원에게 파일 발송`**: C열 이메일 주소로 일괄 발송 (E열에 발송 완료가 기록되어 중복 발송 방지)
